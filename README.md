# 蛋仔守城 V2

依照 [第二版完整遊戲設計規格書](docs/game-v2-design.html)（以及 [第一版規格參考](docs/game-v1-spec.md)）實作的 **8 關卡橫向守城網頁遊戲**。整合全 8 種武器與 10 種怪物軍團。

## 本機預覽

```sh
python3 -m http.server 4173 --directory dist
```

開啟 `http://localhost:4173`。

## 核心玩法與操作

- **電腦**：方向鍵移動，按住 `Space` 連續攻擊，按 `Q`（或點擊畫面下方武器欄）切換已擁有的武器，`Esc` 暫停。
- **手機／平板**：橫向使用，左下虛擬搖桿移動，按住右下攻擊鍵連續攻擊，點擊下方武器欄可切換已擁有武器。
- **城門耐久度（200 HP）**：每關城門擁有 200 HP，怪物抵達城門或魔法師詠唱法術會扣除對應攻擊力的城門耐久；無傷通關可獲得 +10% 完美守城獎金。
- **補給小舖與武器升星**：每關過關後皆開放商店，可購買新武器或將已擁有武器升至 ★2（傷害 +25%）、★3（傷害 +50%）。

## 專案結構

- `dist/index.html`：遊戲界面與流程畫面。
- `dist/styles.css`：響應式介面、城門血條 HUD、商店與觸控操作。
- `dist/game.js`：8 關卡狀態、10 種怪物生成與特殊行為、8 把武器攻速與爆破判定、商店升星與重試回滾邏輯。
- `docs/game-v2-design.html`：第二版完整遊戲規則、武器與怪物數值及 8 關卡平衡設計書（HTML 圖文版）。
