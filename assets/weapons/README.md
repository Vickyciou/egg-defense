## 資料夾

- `final/`：去除紙張、文字與雜線後的透明背景遊戲素材。
- `source-crops/`：從原始照片裁出的手繪造型參考，方便日後比對與重製。
- `weapons.json`：程式可讀取的武器資料與素材路徑。

攻擊力與購買金額已依據 8 關戰役的怪物血量（20 ～ 1000 HP）與金幣產出曲線完成平衡調整，程式資料使用 `attackPower` 欄位。
